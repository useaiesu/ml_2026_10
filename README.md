# ml_2026_10

NumPy만으로 신경망을 직접 구현하며 기계학습을 공부한 기록입니다. (2026.10 ~)

## 목표
- 라이브러리 없이 순전파와 역전파를 직접 구현한다.
- 손글씨 숫자(0~9) 인식기를 만든다.
- 학습 전략(가중치 초기화, 학습률 감소, 드롭아웃)을 실험으로 비교한다.

## 진행 상황
| 단계 | 내용 | 관련 개념 | 상태 |
|---|---|---|---|
| 1 | 2개 클래스 분류 | 시그모이드, 역전파 | ⏳ |
| 2 | `NeuralNet` 클래스로 정리 | 행렬 연산, 배치 | ⏳ |
| 3 | 10개 클래스 분류 | ReLU, 소프트맥스, 크로스엔트로피 | ⏳ |
| 4 | 정확도 개선 | He 초기화, 학습률 감소, 드롭아웃 | ⏳ |

## 실행 환경
- Python 3.13
- NumPy, Matplotlib
